# Java Bus Ticket Booking System (TiketBus)

Aplikasi CLI (Command Line Interface) berbasis Java untuk pemesanan tiket bus antarkota. Proyek ini dikembangkan untuk mendemonstrasikan penerapan konsep **Object-Oriented Programming (OOP)** di Java.

## Fitur Utama
* **Interface & Abstract Class:** Menggunakan implementasi `Interface` (`TicketInfo`) dan `Abstract Class` (`Person`) untuk struktur kode yang modular[cite: 6].
* **Pilihan Rute Fleksibel:** Menyediakan berbagai rute bus populer, termasuk rute antarkota antarprovinsi (seperti Malang - Surabaya, Malang - Jakarta, hingga Malang - Bima)[cite: 6].
* **Sistem Interaktif:** Menggunakan `Scanner` untuk input data pengguna secara *real-time* di terminal[cite: 6].

## Teknologi yang Digunakan
* **Bahasa Pemrograman:** Java
* **IDE:** Apache NetBeans

## Cara Menjalankan
1. Clone repositori ini atau download file ZIP-nya.
2. Buka proyek melalui Apache NetBeans.
3. Jalankan file `TiketBus.java`.
